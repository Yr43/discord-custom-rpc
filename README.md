# discord-custom-rpc
Приложение на Python с GUI и треем для кастомного статуса (Rich Presence) в Discord. (с использывание аи))
## Изменения в версии 2

Во второй версии приложение превратилось из простого окошка в фоновое приложение с работой в трее и автоподключением.

### Основное

- Добавлен **системный трей**.
- При закрытии окна приложение теперь не закрывается, а **сворачивается в трей**.
- Приложение запускается **свернутым**.
- Добавлено **автоподключение** к Discord после запуска.
- Добавлены **автоматические переподключения**, если Discord недоступен.
- Добавлена фоновая проверка состояния каждые **20 секунд**.
- Добавлено меню трея:
  - **Показать**
  - **Подключить**
  - **Обновить**
  - **Отключить**
  - **Выход**

### Интерфейс

- Добавлен индикатор статуса:
  - `Не подключено`
  - `Подключение...`
  - `Подключено`
  - `Статус обновлён`
  - `Отключено`
  - `Ошибка библиотеки`
  - `Discord не запущен или недоступен`
- Статус подсвечивается цветом:
  - красный — ошибка/отключено
  - оранжевый — подключение
  - зелёный — подключено/обновлено

### Технические изменения

- Добавлена библиотека `pystray` для трей-иконки.
- Добавлена библиотека `Pillow` для генерации иконки.
- Добавлена многопоточность через `threading`.
- Подключение и обновление статуса теперь вынесены в отдельные потоки, чтобы интерфейс не зависал.
- Добавлен `threading.Lock` для более безопасной работы с состоянием подключения.
- Логика подключения изменена:
  - вместо `connect()` теперь `start_connect()`
  - вместо `update_status()` теперь `refresh_status()`
- Добавлены служебные методы:
  - `_connect_worker()`
  - `_update_rpc()`
  - `_read_values()`
  - `_disconnect_worker()`
  - `_shutdown_worker()`
  - `heartbeat()`
- Добавлен флаг `auto_reconnect`.
- Добавлен флаг `exiting`.
- Добавлено сохранение времени начала активности через `start_time`.

### Зависимости

Для первой версии было достаточно:

```bash
pip install pypresence
```

Для второй версии нужно:

```bash
pip install pypresence pystray pillow
```
